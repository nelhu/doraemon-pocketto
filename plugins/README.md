# Plugins

本目录用于存放本地插件、插件开发资料及其配置示例。

## 组织方式

每个 plugin 使用独立目录：

```text
plugins/
└── example-plugin/
    ├── README.md
    ├── src/           # 可选：插件源码
    ├── config/        # 可选：安全的配置示例
    └── assets/        # 可选：插件资源
```

插件 README 应说明用途、安装方式、运行环境、配置项、验证方式和已知限制。外部插件需要记录来源、版本和许可证。

## 安全

- 真实凭据放在本地环境变量或未跟踪的配置文件中。
- 提交配置示例前删除内部地址、个人信息和敏感参数。
- 升级插件时记录不兼容变更和迁移步骤。
