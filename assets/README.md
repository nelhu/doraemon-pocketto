# Assets

本目录用于存放日常 AI 创作所需的公共素材。

## 建议分类

```text
assets/
├── images/
├── audio/
├── video/
├── fonts/
└── templates/
```

仅在有实际素材时创建对应子目录。某个 skill 或 plugin 独占的素材应优先放入其自身的 `assets/`，避免公共目录失去边界。

## 素材约定

- 文件名使用清晰、稳定的英文 kebab-case，避免 `final-v2-new` 一类名称。
- 对外部素材记录来源、作者、许可证和允许的使用范围。
- 大文件加入仓库前先评估体积；必要时使用 Git LFS 或外部存储。
- 不提交包含个人隐私、商业机密或使用权不明确的素材。
